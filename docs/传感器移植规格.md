# Safex 传感器模块移植规格书

> **文档版本**: 1.0
> **编写日期**: 2026-07-03
> **目标平台**: Air8000A (LuatOS, Lua 5.3)
> **来源**: 从 STM32L431RCT6 移植
> **详细传感器规格**: [传感器及外设规格.md](传感器及外设规格.md)
> **引脚定义**: [引脚定义文档.md](引脚定义文档.md)

---

## 1. 移植目标

将 STM32 主控上的传感器采集、报警管理、IO 控制、LCD 显示、Flash 存储功能移植到 Air8000A，使 Air8000 成为唯一主控（不再依赖 STM32）。

UART1 通信保留用于调试（`$SAFE` 协议 + 串口日志），后续可按需移除。

## 3. 阶段计划

### 阶段 1：地基 — 更新 `app_data.lua`

**目标**: 为新模块预埋数据结构和接口，不改动现有逻辑。

**变更内容**:
1. `data.config` 新增 11 个开关字段（`sensor_pid_en`、`sensor_mos_en`、`sensor_sht30_en`、`sensor_ims_en`、`sensor_battery_en`、`sensor_report_en`、`buzzer_en`、`pump_en`、`lcd_en`、`flash_en`、`key_en`）
2. `data` 新增 3 个数据表：`sensor`（pid/mos/sht30/ims/battery）、`alarm`、`io`（led/buzzer/pump/key/lcd/flash）
3. 新增 3 个接口：`update_sensor(sub, fields)`、`update_alarm(level, source)`、`update_io(category, fields)`
4. `get_report_data()` 新增 sensor/alarm/io 上报过滤逻辑

**不改动**: UART1 收发、现有模块数据表（ble/gnss/gsensor/mqtt/ota/uart1/sys）、现有接口

**验证方法**: 烧录后通过串口 `$SAFE,GET,config` 确认新开关存在，`$SAFE,CFG,sensor_pid_en=0` 可切换

---

### 阶段 2：骨架 — 基础 GPIO 模块

**目标**: 验证硬件接线正确性，LED/蜂鸣器/按键可工作。

| 模块 | 验证方法 |
|------|---------|
| `mod_led` | `$SAFE,CFG,...` 后 LED 亮灭；电源灯常亮 |
| `mod_buzzer` | 蜂鸣器响/停/间歇鸣响 |
| `mod_key` | 按键触发串口日志 + 蜂鸣器提示音 |

---

### 阶段 3：血肉 — 传感器采集模块

**目标**: 各传感器独立可采集，数据写入 `app_data`。

| 模块 | 验证方法 |
|------|---------|
| `mod_pid` | `$SAFE,GET,sensor` 看到 pid 浓度值 |
| `mod_mos` | `$SAFE,GET,sensor` 看到 mos 浓度值 |
| `mod_battery` | `$SAFE,GET,sensor` 看到电池电压 |
| `mod_sht30` | `$SAFE,GET,sensor` 看到温湿度 |
| `mod_ims` | UART12 收到数据日志（协议待确认） |
| `mod_pump` | 泵启动/调速/停止 |

---

### 阶段 4：神经 — 逻辑层 + 存储

**目标**: 传感器自动调度，报警联动外设，数据可持久化。

| 模块 | 验证方法 |
|------|---------|
| `mod_alarm` | PID 超阈值 → 蜂鸣器响 + LED 快闪 |
| `mod_sensor` | 每秒自动采集所有传感器 |
| `mod_flash` | 报警记录写入 Flash，重启后可读 |

---

### 阶段 5：皮肤 — 显示 + 集成

**目标**: LCD 显示传感器数据，全部模块集成到 `main.lua`。

| 模块 | 验证方法 |
|------|---------|
| `mod_lcd` | LCD 显示浓度/温度/报警状态 |
| `main.lua` | 全模块启动，无报错 |
| 文档更新 | `readme.md`、`通信协议文档.md` 同步 |

---

## 4. 架构约束

1. **星型架构** — 所有模块只与 `app_data` 交互，模块间禁止直接调用
2. **config 开关** — 每个模块检查自己的开关，关闭时停止工作且数据不上报
3. **init() + start()** — 每个模块对外提供这两个接口
4. **非阻塞** — 全程协程 + `sys.wait()`，无阻塞调用
5. **故障降级** — 传感器异常记录日志不中断系统
6. **AI 署名** — 文件头标注 `🤖 整体或部分由 opencode 生成`

## 5. app_data.lua 变更明细（阶段 1）

### 5.1 config 新增字段

```lua
-- 传感器开关
sensor_pid_en     = true,
sensor_mos_en     = true,
sensor_sht30_en   = true,
sensor_ims_en     = true,
sensor_battery_en = true,
sensor_report_en  = true,
-- 外设开关
buzzer_en         = true,
pump_en           = true,
lcd_en            = true,
flash_en          = true,
key_en            = true,
```

### 5.2 新增 data.sensor 表

```lua
sensor = {
    pid = { conc=0, raw_adc=0, voltage=0, alarm=false, timestamp=0 },
    mos = { conc=0, raw_adc=0, voltage=0, alarm=false, timestamp=0 },
    sht30 = { temperature=0, humidity=0, timestamp=0 },
    ims = { status=0, alarm_count=0, alarm_names={}, pos_peak={}, neg_peak={}, timestamp=0 },
    battery = { voltage=0, pct=0, timestamp=0 },
}
```

### 5.3 新增 data.alarm 表

```lua
alarm = { level=0, source="none", timestamp=0 }
```

### 5.4 新增 data.io 表

```lua
io = {
    led    = { power=false, alarm="off", comm="off" },
    buzzer = { pattern="off", timestamp=0 },
    pump   = { pump1_enable=false, pump1_speed=0, pump2_enable=false, pump2_speed=0 },
    key    = { last_key="", key_event="", timestamp=0 },
    lcd    = { connected=false, last_refresh=0, timestamp=0 },
    flash  = { mounted=false, size_kb=0, free_kb=0, timestamp=0 },
}
```

### 5.5 新增接口

```lua
-- 更新传感器子表（sub: "pid"/"mos"/"sht30"/"ims"/"battery"）
app_data.update_sensor(sub, fields)

-- 更新报警状态
app_data.update_alarm(level, source)

-- 更新 IO 子表（category: "led"/"buzzer"/"pump"/"key"/"lcd"/"flash"）
app_data.update_io(category, fields)
```

### 5.6 get_report_data() 过滤逻辑新增

| 数据模块 | 上报条件 |
|---------|---------|
| `sensor.pid` | `sensor_pid_en=true` 时上报 |
| `sensor.mos` | `sensor_mos_en=true` 时上报 |
| `sensor.sht30` | `sensor_sht30_en=true` 时上报 |
| `sensor.ims` | `sensor_ims_en=true` 时上报 |
| `sensor.battery` | `sensor_battery_en=true` 时上报 |
| `alarm` | 始终上报 |
| `io` | 始终上报 |
