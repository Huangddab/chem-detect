# Safex 屏幕地图显示 — 开发文档

> **文档版本**: 1.0  
> **编写日期**: 2026-07-24  
> **模块**: `mod_screen_map.lua`  
> **屏幕型号**: TJC X5 (800×480 竖屏)  
> **SD 卡**: 插在屏幕侧，屏幕自行读取瓦片图片

---

## 1. 系统架构

```
Air8000 (mod_screen_map.lua)
│
├── 1. 读取 GPS 坐标 (app_data.get().gnss, rmc(2) 十进制)
├── 2. 计算瓦片编号 + 偏移量
├── 3. 通过 UART 发送 TJC 指令:
│      ├── path 指令 → 屏幕从 SD 卡加载瓦片图片
│      ├── x/y 指令 → 设置 4 块瓦片的屏幕位置（偏移滚动）
│      └── t2/t3 指令 → 显示经纬度文本
│
TJC X5 屏幕 (480×800 竖屏, 地图区 480×480)
├── 4 个图片控件: exp0(左上) exp1(右上) exp2(左下) exp3(右下)
├── 从 SD 卡读取 .xi 格式瓦片图片
├── 4 块瓦片一起偏移 → 实现地图滚动
└── 标记点固定在屏幕中心 (240, 400)
```

### 2.2 瓦片布局

瓦片原始 256×256，放大 2 倍为 **512×512**，4 块拼成 1024×1024：

```
  ┌───────────────┬───────────────┐
  │               │               │
  │    exp0       │    exp1       │
  │   (左上)      │   (右上)      │

  │               │               │
  │               │               │
  │       240,400 ★ ← 中心标记     │
  ├───────────────┼───────────────┤  y=400
  │               │               │
  │    exp2       │    exp3       │
  │   (左下)      │   (右下)      │
  │  x=-272       │  x=240        │
  │               │               │
  │               │               │
  └───────────────┴───────────────┘

  初始位置 (偏移 dx=0, dy=0):
    exp0: x=-272, y=-112
    exp1: x= 240, y=-112
    exp2: x=-272, y= 400

  滚动时 (偏移 dx, dy):
    exp0: x=-272+dx, y=-112+dy
    exp1: x= 240+dx, y=-112+dy
    exp2: x=-272+dx, y= 400+dy
    exp3: x= 240+dx, y= 400+dy
```

### 2.3 GPS 坐标转瓦片

```lua
-- 输入: WGS84 十进制经纬度 (exgnss.rmc(2) 格式)
-- 输出: 瓦片编号 (tile_x, tile_y) + 瓦片内像素 (px, py)

local PI = 3.14159265358979323846
local TILE_SIZE = 256   -- 原始瓦片大小
local TILE_SCALE = 2    -- 放大倍数 (256→512)

-- 经度 → 瓦片X (浮点)
local function lon2tile(lon, zoom)
    return (lon + 180.0) / 360.0 * (2 ^ zoom)
end

-- 纬度 → 瓦片Y (浮点)
local function lat2tile(lat, zoom)
    local lat_rad = lat * PI / 180.0
    local n = 2 ^ zoom
    return (1.0 - math.log(math.tan(lat_rad) + 1.0 / math.cos(lat_rad)) / PI) / 2.0 * n
end

-- 完整计算
local function calc_tile(lat, lng, zoom)
    local tx_f = lon2tile(lng, zoom)    -- 浮点瓦片X
    local ty_f = lat2tile(lat, zoom)    -- 浮点瓦片Y
    local tile_x = math.floor(tx_f)     -- 整数瓦片X
    local tile_y = math.floor(ty_f)     -- 整数瓦片Y
    local px = (tx_f - tile_x) * TILE_SIZE  -- 瓦片内像素X (0~255)
    local py = (ty_f - tile_y) * TILE_SIZE  -- 瓦片内像素Y (0~255)
    return tile_x, tile_y, px, py
end
```

### 2.4 偏移量计算

```lua
-- base 瓦片: 初始加载时的中心瓦片 (GPS点所在瓦片)
-- 当 GPS 点在瓦片内移动时，计算与 base 瓦片的偏移
--
-- px, py: GPS点在当前瓦片内的像素位置 (0~255)
-- base_px, base_py: base 瓦片加载时 GPS 点的像素位置
--
-- 放大 2 倍后，1 像素偏移 = 2 屏幕像素

local function calc_offset(px, py, base_px, base_py)
    local dx = (px - base_px) * TILE_SCALE  -- 屏幕像素偏移X
    local dy = (py - base_py) * TILE_SCALE  -- 屏幕像素偏移Y
    return dx, dy
end
```

### 2.5 瓦片切换条件

```
当 |dx| >= 256 或 |dy| >= 256 时:
  1. 切换 base 瓦片编号
     - dx >= 256  → base_x += 1 (GPS 向东走，地图向左滚)
     - dx <= -256 → base_x -= 1 (GPS 向西走，地图向右滚)
     - dy >= 256  → base_y += 1 (GPS 向南走，地图向上滚)
     - dy <= -256 → base_y -= 1 (GPS 向北走，地图向下滚)
  2. 更新 base_px, base_py 为当前 GPS 像素位置
  3. dx, dy 归零
  4. 重新发送 4 个 SD 卡路径

余量分析:
  瓦片放大后 512px，中心到瓦片边缘 512px
  切换阈值 256px (=SCALED_TILE/2, 半瓦片)，余量 = 512 - 256 = 256px
  → 切换时不会出现空白
```

## 3. SD 卡路径格式

```
sd0/{zoom}/{tile_x}/{tile_y}.xi

示例 (zoom=16, 深圳坐标):
  exp0 (左上): sd0/16/21433/104017.xi
  exp1 (右上): sd0/16/21434/104017.xi
  exp2 (左下): sd0/16/21433/104018.xi
  exp3 (右下): sd0/16/21434/104018.xi

4 块瓦片的编号关系:
  exp0 = (base_x,   base_y)
  exp1 = (base_x+1, base_y)
  exp2 = (base_x,   base_y+1)
  exp3 = (base_x+1, base_y+1)
```

## 4. TJC 指令设计

### 4.1 设置图片路径

```lua
-- 格式: exp0.path="sd0/16/21433/104017.xi"
send_cmd(string.format('exp0.path="sd0/%d/%d/%d.xi"', zoom, tile_x, tile_y))
```

### 4.2 设置图片位置（偏移）

```lua
-- 格式: exp0.x=-272
send_cmd(string.format('exp0.x=%d', -272 + dx))
send_cmd(string.format('exp0.y=%d', -112 + dy))
-- exp1/exp2/exp3 同理
```

### 4.3 坐标文本

```lua
-- t2 = 经度, t3 = 纬度
send_cmd(string.format('t2.txt="%.5f"', lng))
send_cmd(string.format('t3.txt="%.5f"', lat))
```

### 阶段 2+3: 阈值方式瓦片滚动与切换 ✅

**目标**: 方向键移动地图时，偏移 <256px 只做滚动，>=256px 智能切换瓦片。

**核心算法 (阈值方式)**:

```
base_tx, base_ty  -- 锺点瓦片编号 (固定锚点)
base_px, base_py  -- 锺点在瓦片内像素 (固定锚点)

每次方向键移动:
  1. 计算新坐标的瓦片编号 new_tx, new_ty 和像素 new_px, new_py
  2. 计算相对 base 的有效像素:
     eff_px = new_px + (new_tx - base_tx) * 256
     eff_py = new_py + (new_ty - base_ty) * 256
  3. 计算屏幕偏移 (放大后):
     offset_x = (eff_px - base_px) * 2  -- 屏幕像素
     offset_y = (eff_py - base_py) * 2
  4. 阈值判断:
     if |offset_x| >= 256:
       shift_tx = sign(offset_x) * 1  -- 只在 shift 后更小时才切换
       base_tx += shift_tx            -- 瓦片反方向移动
       smart_switch(base_tx, base_ty) -- 加载新瓦片 (复用旧瓦片)
       重新计算 eff_px, offset_x       -- 余值出现在另一侧
  5. update_tile_positions_dynamic(eff_px, eff_py)
```

**智能切换 (smart_switch)**:
- 复用仍在视野内的旧瓦片 (不发 path 指令)
- 只对新增瓦片发送 path 指令 (减少 SD 卡读取)
- 动态映射控件 → 瓦片位置 (不固定 exp0=左上)

**余值效果**:
- 切换前: offset = 300px (东向)
- 切换后: offset = 300 - 512 = -212px (出现在西侧)
- 瓦片反向移动 512px 抵消了 300px 偏移，余值 -212px 留在另一侧

**无死区设计**:
- 阈值 256 = 半瓦片 (SCALED_TILE/2)，是数学上的精确平衡点
- |offset| < 256: shift 后偏移变大，不切
- |offset| > 256: shift 后偏移变小，切换
- 不存在死区，每次到达阈值即切换

**状态**: ✅ 已完成
